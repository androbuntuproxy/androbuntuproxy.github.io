从入门到精通：iOS 上的 Shadowrocket 完全使用教程与配置指南

在当今这个信息爆炸、网络边界日益模糊的时代，数字生活的自由与安全已经成为每一位 iOS 用户无法回避的议题。无论是为了突破地域限制获取全球资讯，还是为了保护个人隐私免受窥探，一款强大而灵活的网络工具都是不可或缺的。而在众多 iOS 网络代理应用中，Shadowrocket（俗称“小火箭”）无疑是一颗璀璨的明星。它不仅仅是一个简单的代理客户端，更是一个集协议支持、精细流量控制、强大规则引擎于一体的网络瑞士军刀。本文将从零开始，为你详细拆解 Shadowrocket 的下载、安装、配置乃至高级玩法，带你彻底驾驭这款工具，让网络世界在你指尖自由驰骋。

初识 Shadowrocket：它到底是什么？

Shadowrocket 是一款运行在 iOS 平台上的网络代理工具，它的核心功能是拦截并转发设备的网络请求，通过预设的服务器链路，实现加密传输和匿名访问。与许多同类工具不同，Shadowrocket 的魅力在于其“链式代理”与“规则分流”的机制。它允许你将不同的流量（例如：国内网站、国外网站、特定应用）分别导向不同的代理通道，从而实现“国内直连、国外代理”的智能切换，既保证了访问速度，又突破了网络限制。

更重要的是，Shadowrocket 拥有极高的可配置性。它支持包括 Shadowsocks（SS）、Vmess（VM）、Trojan、HTTP(S) 代理在内的多种主流协议，这意味着你几乎可以接入任何主流机场或自建服务器。同时，其内置的规则系统允许用户通过编写或导入规则集，实现基于域名、IP、端口乃至具体应用的精细化流量分流。对于追求极致网络体验和高度自定义的用户来说，Shadowrocket 几乎无可替代。

获取 Shadowrocket：绕过 App Store 的“常规”路径

一个令人遗憾的事实是，由于各种原因，Shadowrocket 在中国区的 App Store 中已无法直接搜索到。但这并不意味着无法安装。对于国内用户，通常有以下几种方式获取：

  1. 切换 Apple ID 区域：这是最官方、最安全的方法。你需要准备一个海外地区的 Apple ID（如美区、港区等）。在 App Store 中退出当前账号，登录海外账号，搜索“Shadowrocket”即可购买下载。请注意，该应用是付费应用（通常为 2.99 美元），你需要有对应地区的支付方式，如礼品卡或 PayPal。
  2. 使用 TestFlight：某些开发者会在 TestFlight 上发放有限的测试名额。但 Shadowrocket 作为成熟商业应用，此途径不稳定且不常用。
  3. 第三方应用商店：部分第三方 iOS 应用商店（如各种企业签名平台）会提供该应用的安装包。但此类方法存在隐私泄露和封号风险，且证书易被吊销，导致应用无法打开，需要反复重新安装，极不推荐。

核心提示：无论采用哪种方式，一旦安装成功后，你都需要进行一个关键步骤——信任证书。由于 Shadowrocket 并非通过 App Store 官方审核分发（指企业签或自签方式），iOS 会默认阻止其运行。你需要进入 “设置” -> “通用” -> “VPN 与设备管理”（旧版本为“设备管理”），找到对应的企业级 App 信任证书，点击“信任”即可。完成这一步，你的小火箭才能正式起飞。

首次启动：从零开始配置你的代理

安装并信任证书后，打开 Shadowrocket，你会看到它简洁的界面。首次使用，我们需要完成最基础的服务器配置。

1. 添加代理服务器节点

Shadowrocket 的首页是一个服务器列表。点击右上角的“+”号，你会看到多种添加方式。最常用的是“手动添加”和“扫码添加”。

  • 手动添加：如果你有服务器信息，选择类型（如 Shadowsocks、Vmess），然后依次填写服务器地址、端口、密码、加密方式。对于 Vmess 协议，还需要填写 UUID 和 AlterId（通常为 0）。
  • 扫码添加：大多数机场都会提供配置二维码。你只需点击“扫码添加”，扫描二维码，所有信息便会自动填入，非常便捷。

2. 理解并选择全局路由模式

这是 Shadowrocket 的灵魂配置之一。在首页顶部，你会看到“全局路由”选项，点击它，通常有三个模式：

  • 配置：这是最智能的模式。它完全按照你导入的规则集（Conf）来分流流量。例如，规则中定义“国内域名直连、国外域名走代理”，那么当你访问百度时直连，访问 Google 时走代理。这是最推荐日常使用的模式。
  • 代理：所有流量均通过代理服务器转发。这会导致国内访问速度变慢，且消耗代理流量，一般仅在特定测试或需要隐藏全部 IP 时使用。
  • 直连：不使用任何代理，等同于关闭 Shadowrocket。适合在不需要代理或排查问题时使用。

对于绝大多数用户，选择“配置”模式，并搭配一份优秀的规则集（可以在网上搜索“Shadowrocket 规则”或“lhie1 规则”等，导入后即可实现智能化分流），就能获得极佳的上网体验。

进阶玩法：打造你的专属网络规则

Shadowrocket 的进阶魅力在于其强大的规则引擎。它允许你像编写防火墙规则一样，对每一个连接进行精确控制。

1. 自定义规则项

在“配置”模式下，点击首页右上角的“设置”图标（或齿轮图标），找到“规则”选项。你可以添加以下类型的规则：

  • 域名规则：例如 DOMAIN-SUFFIX, google.com, PROXY 表示所有以 google.com 结尾的域名都走代理；DOMAIN-KEYWORD, baidu, DIRECT 表示域名中包含 baidu 的直连。
  • IP 规则：例如 IP-CIDR, 192.168.1.0/24, DIRECT 表示局域网内 IP 直连。
  • 应用规则：这是 Shadowrocket 的拿手好戏。你可以指定某个 App（如 YouTube）强制走代理，而另一个 App（如银行应用）强制直连，避免因代理 IP 导致风控。

通过组合这些规则，你可以实现“看视频走高速代理，刷网银走本地网络”的完美状态。

2. HTTPS 解密与抓包（高级）

Shadowrocket 甚至内置了 HTTP(S) 抓包功能。通过安装并信任其生成的 CA 证书，你可以查看 App 的 HTTPS 请求内容。这对于开发者调试接口或普通用户分析应用行为非常有用。但请注意，此操作有安全风险，切勿在非受信网络下随意开启。

深度体验：流量监控与性能优化

Shadowrocket 不仅是一个代理工具，还是一个优秀的网络诊断器。

  • 实时流量统计：首页的每个节点卡片下，都会显示实时的上传/下载速度。点击进入节点详情，你可以看到该节点今日已消耗的流量。
  • 连接日志：在“设置”中开启“日志”功能，你可以看到每一条连接的去向、协议、耗时。当某个 App 无法访问时，日志能帮你快速定位是直连还是代理出了问题。
  • 延迟测试：在服务器列表页，长按某个节点，选择“测试延迟”，Shadowrocket 会发送一个 HTTP 请求到指定服务器（通常是 Google），显示连接延迟。这帮助你选择当前网络环境下最快的节点。

常见问题与解决策略

在使用过程中，你可能会遇到一些棘手的问题，这里给出一些典型的解决方案：

  1. 无法连接，一直转圈：首先检查服务器信息是否正确（端口、密码）。其次，尝试切换“全局路由”为“代理”模式，以排除规则误判。最后，检查手机是否开启了“低数据模式”或“VPN”冲突（iOS 原生 VPN 与 Shadowrocket 冲突，需关闭）。
  2. 电池掉电快：Shadowrocket 作为网络代理，长期在后台运行会消耗电量。你可以在 iOS 设置中关闭它的后台刷新，但这样可能导致代理连接中断。更优解是，在 Shadowrocket 的“设置”中，开启“仅在前台工作”或“按需连接”，让它在锁屏后自动断开，使用时再连接。
  3. 某些 App 无法使用（如银行）：这通常是代理 IP 被风控所致。解决方案是在“规则”中添加该 App 为“直连”（USER-AGENT, 或 DOMAIN-SUFFIX, bank.com, DIRECT），确保其流量不经过代理服务器。

总结与点评

Shadowrocket 早已超越了一款简单工具的定义，它更像是一个属于网络极客的“变形金刚”。初看时，它简洁的界面可能会让你低估它的能量，但一旦你深入了解其规则引擎、协议支持和抓包能力，你会惊叹于它的深度与广度。

优点： - 功能强大到极致：协议支持全面，规则系统灵活到令人发指，几乎可以满足任何网络定制需求。 - 性能优异：在同类工具中，其连接速度和稳定性表现上乘，内存占用控制得当。 - 界面精美：UI 设计现代且直观，即便功能繁多，也并未显得杂乱无章。

缺点： - 上手门槛高：对于纯小白来说，理解“规则”、“分流”、“协议”等概念需要一定学习成本。 - 获取困难：由于下架问题，安装过程对国内用户并不友好。

总评：Shadowrocket 是当之无愧的 iOS 代理工具之王。它适合那些愿意花一点时间去研究、希望真正掌控自己网络流量的用户。如果你愿意投入这半小时的学习时间，它回馈给你的将是无比顺畅、安全且自由的网络体验。它不仅仅是一个工具，更是你通往无界数字世界的钥匙。如果你追求极致，那么 Shadowrocket 绝对值得你拥有。

FAQ

Sing-box 的策略组如何实现按域名分流？
Sing-box 支持根据域名规则匹配流量，将不同网站或应用流量分配到指定节点。结合策略组自动切换低延迟节点，可优化访问速度，保证网络稳定性和流畅体验。
PassWall2 如何自动切换最佳节点？
通过延迟测速和策略组设置，PassWall2 可自动选择延迟最低的节点处理流量。用户无需手动切换节点，保证网页、视频和游戏流量的速度和稳定性，提高整体网络体验。
Potatso Lite 的节点测速功能有何局限？
Potatso Lite 节点测速只能显示延迟，无法测出带宽或实际下载速度。此外，测速结果受网络波动影响较大，建议结合实际使用体验来判断节点性能。
Clash 如何防止规则文件冲突导致分流异常？
合理组织规则顺序，将更具体的规则放在前面，通配规则放在末尾；使用 rule-providers 分离不同来源的规则，避免重复条目，并在变更后使用日志或 debug 模式检验分流是否按预期生效。
PassWall2 能运行在哪些设备上？
PassWall2 是基于 OpenWRT 的插件，只要路由器支持该固件，就能安装运行。常见型号如小米路由、斐讯、软路由都可以使用，通过 Web 界面操作，适合家庭网络使用场景。
Shadowrocket 支持自动测速吗？
支持。Shadowrocket 可以批量测速节点延迟并标记最佳连接。用户还可设置自动切换到最低延迟节点，实现稳定高速的上网体验，尤其在网络波动较大的环境中效果明显。
Sing-box 如何按 IP 段实现智能分流？
Sing-box 支持根据 IP 段匹配流量，将国内流量直连、国外流量走代理。结合策略组和规则文件，实现精细化流量管理，保证访问速度和稳定性，同时提高节点使用效率。
如何用 iptables 限制 V2Ray 服务的访问来源？
使用 iptables 规则仅允许可信 IP 或 CDN 的中转 IP 访问服务端口，例如 `iptables -A INPUT -p tcp -s --dport 443 -j ACCEPT`，并在默认策略下拒绝其他来源，从而降低被扫描与滥用风险。
Surfboard 的规则文件如何支持广告屏蔽？
规则文件可添加广告域名或 URL 列表，将请求重定向或阻断。结合策略组和自动更新，Surfboard 可实现全局广告屏蔽，提高浏览体验并节省带宽。
SSR 节点和 V2Ray 节点可以混合使用吗？
可以，但要使用支持多协议的客户端，如 Clash、Sing-box、Mihomo 等。这类客户端能在同一配置文件中加载不同协议的节点，通过规则分流让 SSR 与 V2Ray 同时工作。
